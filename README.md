Tower Builder 2

Tower Builder 2 is the second take on the beam building tower game. It is for anyone who likes to build and test structures.

You place beams of steel, wood, or reinforced concrete between grid nodes within a budget. A test runs wind and then an earthquake against the target height. An info panel explains the rules.
