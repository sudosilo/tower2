Tower Builder 2

Tower Builder 2 is a beam building tower game. It is for anyone who likes to build and test structures.

You place wood, steel, and concrete beams between grid points within a budget, then test the tower against its own weight, a steady wind, and an earthquake. Joints are pins, so only braced triangles hold their shape. Long beams buckle when squeezed, concrete is weak when pulled, and heavy towers suffer in an earthquake. There are six levels with different supports, targets, and budgets, and builds and best scores are kept on the device.
